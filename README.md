# BBN – Business Portfolio Website

A professional portfolio website for **BBN (B.B. Nagrale)** to showcase the business, its products, services, and contact information.

## Features
- Modern and responsive UI
- Image slider with continuous scrolling
- Business and product showcase
- Services and company information
- Contact details for customer inquiries

## Tech Stack
- React.js
- Vite
- CSS

## Getting Started

### 1. Clone the repository
```bash
git clone <your-repository-url>
```

### 2. Navigate to the project folder
```bash
cd <project-folder>
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start the development server
```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## Build for Production
```bash
npm run build
```

## Deployment
The website can be deployed using platforms such as Vercel or Netlify.
